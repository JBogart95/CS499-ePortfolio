Professional Introduction

Professional Self-Assessment

Completing the Bachelor of Science in Computer Science program has been a significant milestone in my professional and personal development. The program strengthened my technical knowledge while expanding my understanding of software engineering, algorithms and data structures, databases, secure development, and professional communication.

My background in Army information technology and enterprise SharePoint administration taught me the importance of mission support, teamwork, troubleshooting, documentation, and communication with both technical and nontechnical stakeholders. My coursework expanded those abilities by giving me practical experience designing and improving full-stack software solutions.

Throughout the capstone, I enhanced the Travlr Getaways application through three connected stages. The software engineering enhancement improved code organization, validation, API responses, error handling, and maintainability. The algorithms and data structures enhancement introduced reusable search, sorting, filtering, unique-value collection, and pagination functionality. The database enhancement strengthened the MongoDB and Mongoose layer through improved data types, validation, indexes, duplicate prevention, secure user data handling, and optimized query behavior.

These enhancements demonstrate that successful software development requires more than producing functional code. Professional-quality solutions must be understandable, maintainable, efficient, secure, and aligned with the needs of users and organizational stakeholders. Moving forward, I plan to combine my enterprise IT experience with software engineering and cloud technologies to develop secure and scalable solutions.
